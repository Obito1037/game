具体形体变化
1. 保留源短草 5 tri、长草 7 tri、少量宽叶 16 tri 的群体比例与分布。
   根部宽度缩为原来的 35%，中段保持 98–100%；根部仅向附近根点靠拢，
   水平位移最多 2 cm。小幅共享朝向、上半部弯势和有限长叶垂尖提供变化。
   没有重新分配全岛草簇，没有宏观 patch 留白删除。
2. 匍匐叶保持原单片根点 XZ，轻微改变宽度、长度、左右非对称和主脉弯势。
   不将每片强制重组成三叶风车；以实际 Island_Meadow BVH 贴合高度。
3. 草叶根边逐顶点设为实际地表下 0.8 mm，匍匐叶根为下 0.6 mm。
   匍匐叶边缘/中脉大部分高出地表约 2–9 mm；还采样三角中心与边中点，
   限制明显埋入或悬空。独立回读结果以 interchange-verification.json 为准。
4. 整片排除实际路径、岩石、灯座、建筑和贴地树干/长椅穿插。
   Hero/灯座另按现 shader 最大风摆方向的 5 个幅度样本检查顶点与三角中心。
   这不是连续时间、连续曲面或所有物体动态碰撞的完整证明。

导入注意
保持现有材质映射与顶点色处理。使用原 BI_leaf 系列材质，未依赖新增 shader。
整片分量按原材质顺序排序，避免 FBX 按首次使用重排材质槽。
FoliageTint 为线性乘色；FBX 以 LINEAR 导出，GLB 包含 COLOR_0。
Blender 的 glTF 回读会转成 BYTE_COLOR，因此需要区分原始 GLB 线性数值与
导入后的 8 位 sRGB 存储量化；不会以任意放宽误差掩盖问题。

实际回读结果
27 非目标 mesh / 14 anchors / 全部使用材质与贴图逐格式一致。
0 退化三角、0 重复三角、0 非有限法线、0 朝下三角。
草有 332 个法线水平的宽叶端面，非退化；未声称所有面法线都严格朝上。
最大位置误差 1.157 微米，最大法线角误差 0.04312 度，根边最大接地误差 1.586 微米。
原始 GLB 线性颜色逐顶点与导出器 UINT16 取整码全部一致，最大线性误差约 7.659e-6。
Blender 导入后的最大源颜色差约 0.0045103，超过旧审计的任意 0.0045 阈值；
本次通过临时 BYTE_COLOR 逐值写读复现本地导入转换，实测模型残差为 0，
因此明确归因到可重现的存储量化，而没有隐藏或简单放宽该误差。
所有资产与贴图文件 SHA256 在审计前后不变。详情见 interchange-verification.json。
