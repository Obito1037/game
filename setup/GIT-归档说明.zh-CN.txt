需要完整当前工程时，使用本轮最终 main 提交；不要将素材目录版本号视为发布标签。

模型源文件与导出文件继续使用 Git LFS。新版纹理、声音、最终截图、
视频、Office 文档、PDF 和 ZIP 也由 Git LFS 保存。克隆前请安装 Git LFS，
克隆后运行 git lfs pull；GitHub 的普通源码 ZIP 不保证包含实际 LFS 大文件。

仓库包含 Unity 工程、原始/处理后模型、生成与验证脚本、历史报告、
v2 r10 与 v3 r2 的最终实机截图，以及参赛提交目录中的成品。
完整流程录像在制作目录与参赛目录中可能重复引用同一内容；LFS 按内容去重。

- 已安装的 Unity/Blender/其他工具、node_modules、下载缓存；
- 浏览器 profile（包括 Cookies、登录状态和网络缓存）；
- art/design/v2/benchmark/reference 等参考网站抓取素材；
- builds 中的各次构建和中间打包（最终参赛 ZIP 已另存于参赛提交）；
- 按既有 .gitignore 排除的旧版生成输出和批量中间测试截图/录屏。
这些文件没有被删除。历史报告可能引用其中的本地资料，需原工作站归档才能打开。
