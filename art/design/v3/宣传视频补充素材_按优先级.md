## 新增提示词

### S07 高清地球全盘贴图（GPT 生图，不进 Tripo）
```
一张 4096×4096 正方形的天体贴图，纯黑色背景。画面正中是一颗从太空远处正面看到的完整地球，占画面约 84%，整个圆盘都被均匀照亮（满月状态），没有明暗交界线：深蓝色的海洋，绿色和赭黄色的大陆轮廓，白色旋涡状云层，边缘有一圈很薄的蓝白色大气光晕。风格是写实但柔和的电影感，略带绘画质感，颜色饱和、干净，细节清楚。只有地球，无星星、无月亮、无文字、无水印。
```
文件名：`v3_S07_earth_full.png`。

### M01 宣传片主题曲（Suno、Udio 或其他 AI 作曲工具）
```
风格：温柔的电影配乐，钢琴主奏 + 弦乐 + 少量钟琴（glockenspiel）与竖琴，像皮克斯/吉卜力动画的片头曲。纯音乐，无人声。
时长：约 75 秒。
结构：0–20 秒，钢琴单音旋律，安静、孤独，像一个人在夜里提着灯走路；20–35 秒，弦乐慢慢进入，温暖起来；35–38 秒，几乎静音，只剩一个钢琴长音（对应画面里灯一盏盏熄灭）；38–60 秒，主旋律在弦乐和钟琴上完整展开、逐渐抬升到高潮（对应满天星河和重逢）；60–75 秒，回落，最后停在一个明亮的钢琴单音上。
情绪关键词：长夜、微光、温柔、希望、不孤单。调性：大调为主，前段带一点小调的忧伤。速度：约 72 BPM。
```
文件名：`v3_M01_theme.mp3`（或 .wav）。

```
约 75 秒的夜晚海岛环境音：轻柔的海浪拍岸，远处偶尔的风声和草叶沙沙声，零星的夜虫鸣叫，偶尔一声远处的铜铃“叮——”。安静、干净、无人声、无音乐，适合垫在配乐下面。
```
文件名：`v3_M02_ambience.wav`。
