日期：2026-10-21

推荐的一项改进
在现有 2048×2048 地表颜色 atlas 中，增加与冻结植物根部位置对应的低幅接触染色。以相邻根部形成的小簇为单位融合柔边暗部，替换现有 Meadow albedo 内容；法线、灯光、几何、植物数量和岩石全部保持现状。
这是地表根部的静态材质近似，不是动态投影阴影或真实 AO。它直接针对当前草根与土面的明暗缺乏关联；不能用它掩盖实际悬浮或宣称整个地景已自然。

一、截图中实际可见的问题
证据：art/verification/run-022-v8/07-walking.png、09-traveler-portrait.png；参考 art/reference/littleprince-gameplay.png。
09 右下提灯照亮的土面呈较连续的黄褐色亮块，许多细草直接从这块亮底色起立；根部缺少随草丛疏密变化的细小暗部过渡。浅色匍匐叶比较零散，植物与地底材质的层次未能连成一体。07 的路径边缘也可见这种关系，但部分被植物密度掩盖。
参考图的草簇根部与近地表有更连续的暗部、杂色和疏密层次。参考是日景，不能仅从截图认定其使用了某种 AO、地表 shader 或接触阴影，也不能据两图推断当前草根几何悬浮。
独立审图复核同意优先尝试根部位置对应的接触染色，而非单独提高法线强度；这仍是待 A/B 验证的候选判断。

二、源码与只读测量
1. 实际 UV 和文件匹配，无需重新展开或放大 atlas。
   冻结 world-v7/island.blend 的 Island_Meadow 为 6,816 三角、单材质 BI_grass。
   WatercolorUV 实测符合 u=(作者坐标 Unity.x+9)/18、v=(作者坐标 Unity.z+9)/18，最大误差 2.9802322388e-8。
   Blender 对应公式为 u=(co.x+9)/18、v=(-co.y+9)/18。
   atlas 覆盖 18×18 米，2048 原级每像素 8.789 毫米。地面法线朝上，Blender Z 分量最小 .94184，没有查到反面地表或 UV 错配证据。
   Unity Resources 的 Meadow.png / MeadowNormal.png hash 与冻结 world-v7 两张源图逐字节一致。
   不应修改 BaseMap tiling：图内已经按绝对路径位置绘制裸土，整体平铺会错开石路和树下区域。

2. 现有图有内容，但接触信息没有与植物关联。
   art/blender/build_island_v6.py:57–121 生成 2048 图；world-v7 继承这两张图。
   5/13/35/90 级场对应约 3.6/1.38/.51/.20 米尺度，泥土 wear 则由四条真实路径距离生成。
   10800 个小椭圆直接随机画在图上，半径 2–5、1–3 像素，大致是数厘米的地表斑点；生成时还没有读取后面实际生成的草根位置。它们不能自然地提供根部接触关系。
   裸土样本 (x=0,z=-5.4，半径 .35m) 线性亮度均值 .35974、标准差 .01177；(0,-3.5，半径 .25m) 为 .34845/.00967。不是纯色图，但局部颜色对比较小。该统计只描述原图，不是实机受光后的像素亮度。

3. Unity 已正确接入图，不能把平涂感简单归因于光滑度或漏贴图。
   WorldDirector.Remap 对 BI_grass 使用 URP/Lit，不经过 Hero 的 PaintedSurface stone 分支。
   Resources/Textures/Meadow 被设置为 _BaseMap，_BaseColor 设为白色；MeadowNormal 被设置为 _BumpMap，启用 _NORMALMAP，_BumpScale=.22。
   草地最终 _Metallic=0、_Smoothness=0，并禁用 SpecularHighlights / EnvironmentReflections。
   颜色图 importer 为 sRGB、2048、mipmap 开、bilinear、aniso 1；normal 为 NormalMap、非 sRGB、2048、mipmap 开、trilinear、aniso 4。当前没有颜色空间或类型配置错误的证据。
   细草、花、蕨类、匍匐叶在 CreateIsland 中关闭 shadowCasting，仍 receiveShadows。PC_Renderer 有启用的 SSAO，不能说整个场景没有接触遮蔽；但现有小植物没有逐根灯光投影，且贴图斑点与根部不对应。

4. 原法线确实很弱，但单独放大不能建立根部对应关系。
   只读解码原 PNG，按本地 URP Packing.hlsl 的 XY 缩放与归一化关系估算：
     mip0 / .22：平均偏角 .669°，P90 1.098°，P99 3.481°。
     mip3 / .22：平均偏角 .168°，P90 .357°。
     mip0 / .45：平均偏角 1.367°，P99 7.092°，最大约 17.848°。
   mip 是理想平均模拟，未测 Unity 的压缩、GPU 采样 LOD、过滤和最终切线空间结果，不能冒称实际 shader 输出角度。
   因此 .22→.45 会加强原有零散斑点的受光起伏，却不会把它们移到草根下面。本轮不叠加该调参，也不同时改颜色图过滤或全局饱和度，以免失去因果可比性。

三、候选如何具体生成
仅在收到实施决定后执行。无需运行完整 build_island_v6.py / build_island_v7.py，不导出新 FBX。

输入与取点：
  只读载入冻结 world-v7/island.blend，首轮只从 Garden_GrassTufts 和 Garden_CreepingMeadowLeaves 提取根部。
  对每个连通叶片组件，取最低高度附近的顶点形成根部中心；排除最低点明显高于对应地面、无法代表根部的组件，避免把叶尖/花头投影当成根。
  通过 Island_Meadow 的实际三角投影确认落点和地表高度。使用其 UV 或已验证的作者坐标公式映射到 atlas；不要使用 Unity 已校准/镜像后的世界 X 直接绘图。
  保留提取数量、被排除组件数、落点 UV 范围，以及至少数个可在俯视证据中核对的根部样本。全部读取，不移动植物。

一层接触颜色：
  根部附近只作中性、低幅亮度压低，不随机增加新斑点，也不沿每片叶子的外轮廓画黑圈。
  单个影响半径先试 .03–.08m（约 3–9 原级像素），随组件/邻近簇尺度变化；近邻落点的柔边自然融合成小片，而非规则的黑色圆点。
  最大线性亮度降低先试 8–12%，外侧平滑归零。合并用 max 或有明确上限的饱和覆盖，不用无限累乘，避免草密处叠成黑毯。
  使用有紧支撑范围的核；没有根部影响的裸土/路径中心保持原像素值，不把整片泥路统一加深。路径边缘真实有草根的位置才允许局部改变。
  暂不额外加入石块投影、树干暗圈、矿物噪声、叶屑图案或新的 normal 内容。它们不是本轮这一个变量。

四、图像、UV 与硬件成本
需要一张新的候选颜色 PNG，尺寸仍为 2048×2048；它替换现有 Meadow 颜色图，不增加运行时纹理槽或纹理数量。MeadowNormal 原文件及 .22 强度保持不变，UV 和纹理 ST 不变。
实现用本地可追溯的程序材质生成/烘色过程，不生成通用照片或随机 AI 土地纹理；必须保留真实草根与 UV 的逐点关系。
在线性空间计算接触乘数，再编码 sRGB PNG；源图本来就是 sRGB 文件，不可把线性 RGB 字节直接作为颜色 PNG 输出，否则会整体变暗。候选 alpha 保持原值；接触掩码外原像素尽量逐字节保留，并报告最大误差。
保持现有 importer 尺寸、mip、压缩及过滤设置作为第一组对照。新增成本主要是离线处理；发布后仍是现有 Lit 的同一次 albedo 采样，无新材质、Renderer、几何、法线采样或每帧计算。
这并不替代实际 Web 检查；A/B 工具若同时载入旧新图会临时多占一张图的内存，不能把该诊断状态当作最终单图内存。

五、最小验证与采用门槛
1. 离线检查：尺寸、色彩空间、alpha、UV 样本通过；掩码外像素不变；所有冻结资产 hash 保持；图内每个改动区域可追溯到真实根部。记录最大/平均线性亮度变化，检查是否有大片接近暗化上限的区域。
2. 实机只换 Meadow 颜色图，normal=.22、曝光、灯强、相机、角色位置、风动/时间保持同一状态，使用 A（原）/B（候选）/A（恢复）截图。复用诊断路径，不增加游戏内设置或玩家操作。
3. 首先看 run-022/09 对应机位的右侧提灯照亮区和脚旁土面，再看 07 路径两侧；应看到草根到土面的细小连续过渡，而不是“整个地面更黑”。A 恢复后变化应消失。
4. 同机位一小段缓慢转镜头检查 mip 后有无黑点闪烁或环状印花；再在浏览器核对同一局部。无需为纯贴图变更重测所有岩石碰撞，但不以静态截图替代地面外观动态检查。
5. 采用门槛：正常游玩尺寸下，至少在提灯根部区有可指认的接地改善，裸土路径亮度和可读性保持，无黑色草毯/逐叶黑圈/远景闪烁。若只能放大截图才能看出、或只表现为整体压暗，直接保留 v8，不把它包装为自然度提升。

诊断产物
  ground-material-inspection.json：只读 UV、贴图 hash、局部亮度与原法线估算。
  inspect_ground_material.py：生成上述证据的只读脚本；没有渲染或写回 blend。
