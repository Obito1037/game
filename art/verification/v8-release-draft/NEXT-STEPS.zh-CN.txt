日常使用：
- 双击上一级目录的 Open-GameProject.cmd 打开项目，建议使用此入口继承正确的代理配置。
- 双击 Open-Blender.cmd 打开 Blender。
- 双击 Game-Tools-Terminal.cmd 打开带 unity、blender 命令的终端。
- 使用 MCP 时保持 GameProject 的 Editor 打开。若当前 Codex 聊天未加载 Unity MCP，重启 Codex 后在本项目新建聊天。
- 只读检查当前状态：
  unity status --json
  unity pipeline list --json
- 检查并保存安装状态：
  powershell -NoProfile -File .\setup\Check-Tools.ps1
- 重新验证 MCP 实际只读调用：
  node .\setup\verify_unity_mcp.mjs --verify-editor

验收证据：
