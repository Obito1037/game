## 自动化验证

- r2 Windows 七章自动流程：`passed-automated-flow`，进入并完成 1–7 章，`errors=[]`，存档恢复（`game-v3-native-r2-full/qa-report.json`，47 张截图，含 11 段开篇）。
- 评审视频由同一套真实按键流程在 Unity 编辑器中录制（`JieGuang/Record Review Video`），1920×1080、30 fps，H.264 + AAC，全程无报错。

## 性能（i5-13500H / Iris Xe / 1600×900，同一固定视角）

- 本机温度对结果影响很大：连续构建测试一小时后，同一版本的 GPU 耗时会从约 17 ms 升到 25 ms 以上。因此只比较相邻、同条件的测量。
- 较凉状态下：v3 在自适应分辨率 0.72 时约 **47 FPS**（GPU 约 17 ms），全分辨率约 44 FPS；r10 全分辨率约 40–41 FPS（`game-v3-abab/`、`game-v3-render-r3/`）。
- 新增内容（海岸、礁石、人物萤光、天空、章节后期、窗光精灵）逐项关闭，每项 GPU 差异都在测量噪声内（`game-v3-render-r3/render-study.json`）。
- 已做的优化：关闭 SSAO（约 2 ms）、灯具硬阴影、阴影距离 38 m、泛光四分之一分辨率、村屋窗光只在镜头 24 m 内点亮（远处用发光精灵），以及两盏过大范围灯光收小。
- **结论：这台集成显卡上尚未稳定达到 60 FPS**，各章均值随温度在 30–55 FPS 之间。

## 闪屏检测

- 方法：被动录屏（不注入任何输入），从窗口出现起逐帧检查右侧 / 上方三分之一是否突然变成纯色。
- v3 r1 与 r2 各录 150 秒（含开机、标题、地图、开篇、序章到第二章）：所有标记帧都是有意的淡入淡出黑场或半黑场，**没有出现画面缩小 + 空白的帧**（`game-v3-flicker-r1/`、`game-v3-flicker-r2/`）。
- 旧版 r10 同样录了 45 秒，也没有抓到。因此原问题没能在本机复现；已修复两处可能的成因（开机离屏渲染、网页整页缩放）。
