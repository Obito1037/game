# 阿婆木屋 v2 离线候选

本候选由 `art/blender/env_v2_props.py` 从 v1 原始 blend 非破坏生成，未写入 Unity Environment、未替换 Island.prefab。

## 文件

- `abode_grandma_v2_candidate.blend`：作者文件。
- `abode_grandma_v2_candidate.fbx`：米制、Y 向上导出；仍需实际 Unity 轴向验证。
- `before-front/side/window.png`、`after-front/side/window.png`：相同机位、相同中性棚灯的三个前后对照，1000×1000。
- `manifest.json`：源与输出 SHA256、实际面数、包围盒、四个 Marker 前后逐值对照、局部圆窗/入口射线及所有网格 UV 检查。
- `REVIEW.html`：六图对照页。

## 已做的造型工作

旧版大平板屋顶及表面凸线替换为成排错层、有弧度的陶瓦；增加原高度包络内的阁楼外观、小窗、低铁皮烟囱。墙体增加独立旧木板、克制的钉头、石脚、檐下木构和金属门窗小件。保留原来的真正开孔圆窗、敞门、桌椅和本子，四个原 Marker 坐标与方向不变。修补旧门楣左侧窄墙缝。

两次几何收敛去掉了背侧多余倒角和过密的钉头；最终三角面数以 manifest 为准，必须不高于 12,000。

## 目视结果和限制

三张候选图显示，屋顶弧度、檐口和阁楼轮廓比旧版清楚，木板与石脚可辨。原始棚拍前后对照只说明造型发生了可见改善，不能证明整岛夜景已经达到对标游戏质量。

目前没有木纹、铜锈、瓦面等 PBR 图，主要使用真实几何和色差；所有网格已生成 UV，下一步可继续配原创表面纹理。阁楼只是外观，没有可上楼的室内或楼梯。新阁楼窗使用未点亮的琥珀材质；剧情点亮需要另接控制接口。

## 接入提醒

1. 先在独立环境测试场景验证导入方向和阴影。不要未经检查重复套用 v1 的 FBX 反射补偿。
2. 保留现有屋根、四个 Marker 与 Island 全部剧情锚点。候选外包围未扩大，但仍应复查人物门口、坐点和所有相关相机。
3. `Structure` 保留旧屋和原圆窗/门洞；`V2_*` 为新增细节。建议保持原玩法碰撞，避免给钉头、瓦片逐件生成碰撞。
4. 本地五条射线只检查圆窗和入口正前方，不证明实际三盏灯全部光锥、角色胶囊和运行时镜头已经通过。
5. 26 个材料槽包含旧材质和色差变体；正式接入前应合批/合并相近材质，不能把离线面数合格当作 draw call 或 FPS 合格。
