## 本轮已写入的实现

这些是源码/资源工作，不等同于九项全部验收通过：

- `Editor/IslandV2Builder.cs`：A01 派生开窗模型、窗边锚点/桌子/碰撞、A13 末端平台、村屋按高度适配、灯头 0.85 倍；A12/A13 按真实板面位置进行对齐。
- `art/blender/v2_house_window.py`：从原 A01 导出可复现的开窗派生 FBX，保留原模型。窗孔在 Blender 中的测量位置为 `(2.0, 1.18, 1.30)`，半径约 `.51 m`。
- `Editor/IslandTerrainBuilder.cs`、草地 shader、`World/IslandFoliageBudget.cs`：用明确引用的网格草/花替代旧 Terrain Grass 渲染依赖，增加石板路径、坡度混合及细节预算。
- `Shaders/NightSea.shader`、`Shaders/NightSkybox.shader`、`World/NightSky.cs`：低波纹暗蓝海、地光/附加灯反射、深度岸沫、天空与章节雾；弃用关键字 `_FORWARD_PLUS` 已换成当前 URP 的 `_CLUSTER_LIGHT_LOOP`。是否零警告仍以最终 Unity 检查为准。
- `Story/StoryProps.cs`、`Core/IslandSoundscape.cs`：小道具的剧情状态，以及环境音、主题与交互音效；`GameDirector` 已调用这两个组件。
- `Story/GameDirector.cs`、`UI/GameUI.cs`：剧情流程与暂停等问题的修正；原标题/地图/章节卡视觉保持现有路线。完整回归见[剧情 QA 表](../game-v2-story/story-qa.txt)。
- `Core/JgQaRunner.cs`：仅 Standalone 且显式 `--jg-qa` 才启动的测试辅助；说明见[原生 QA 运行方式](../game-v2-story/native-qa-runner.txt)。

该次记录的 `enteredChapters` / `completedChapters` 均为 1–7，三次谜题通过正常输入完成，四位尾声 NPC 均访问；`errors` 为空，`saveRestored=true`。但 `unlockValues=[4,4,4,4,5,6]` 不符合干净存档逐段递增，root 已确认历史隐藏进程造成并发存档干扰，须单进程重测。后续 QA 已增加严格解锁序列检查；r2 原报告保留，不改写成干净通过。

低风险性能试验建议（均须固定机位 A/B，未声称已取得收益）：

1. 保持 1600×900 与 renderScale=1，先比较 SSAO `Downsample=false/true`；当前全分辨率 SSAO 对 Iris Xe 是合理的优先排查对象。记录脸、窗框、脚底接触阴影差异。
2. 比较三盏灯的 Soft Shadows 开/关作为诊断，再决定额外灯阴影分辨率或关闭已熄灯的 Light 组件；不要直接牺牲仍在使用的窗/道路阴影。检查四级主光阴影与 50 m 距离的实际必要范围。
3. 已熄灭的人群灯当前仍保留 Light 组件；可将 intensity 近零的灯 `enabled=false`，恢复亮度时再启用，不改变可见剧情。先查实际可见灯计数及 GPU/CPU 证据，不把“灯多”直接当定论。
4. 海/天空已加入低风险裁剪：90 m 外不运行海面附加灯与岸沫；天空地平线下不算星/云，未使用 panorama 时跳过球面采样。r3 原生 07 已验证海方角消失、长反射可见；未做单独隔离海/天空的性能 A/B，不能将整机帧率变化全部归因于此。
5. 若仍需草地预算，再比较 FullDistance 18→14 m、Distance 48→38 m；保留玩家 3 m 近景，不先改全部草密度。降 renderScale 的试验可以记录，但不能当作原生 1600×900 性能通过。

## r3/r4 视觉复核与 r5 待补项

r3 与 r4 的视觉目录各含 11 张 1600×900 PNG。它们是原生尾声固定机位诊断，隐藏 UI 的图不能证明正常 UI/输入流程；`render-study.json` 的 `samples=[]` 也不提供该轮视觉截图的性能数据。02 房前、07 地光海面、08 海岸、09 近草的构图可以对照；06 朝屋海景更换了相机，不能用像素差直接比较改进量。

- **黑地已修复的证据：** [r3 runtime audit](../game-v2-visual-r3/terrain-runtime-audit.txt) 记录 `WindowsPlayer`、Terrain/Lit 支持、4 层、alphamap 256×256；各层权重总和约 11056.389 / 3214.506 / 679.667 / 50585.282，合计约 65536。结合 02 与 09 的实际可见地面，证明本轮 alpha 资源已在原生生效。它不证明陡坡贴图美观。
- **r4 拒绝的证据：** [r4 runtime audit](../game-v2-visual-r4/terrain-runtime-audit.txt) 记录 `_ALPHATEST_ON`、`solidCells=21248/65536`；对比 r3 的 `65536/65536`，08 岸边出现锯齿破片，06 还露出大块悬空三角。02 的 SoftBeam 呈大面积明亮橙锥，掩盖原有层次。两项均需重做。
- **暖倒影仍未通过：** A01 窗灯范围 7.5 m，灯位约 `(5.78,3.7,-17.27)`；海面 `y=-0.16`、前岸 `z=-28` 时最近距离已约 11.40 m。以 r4 的朝屋相机 `(23,2,-25)` 计算，平水面理想反射点约 `(16.82,-0.16,-22.23)`，距灯约 12.70 m。当前海 shader 的真实灯衰减在范围外为零。只增加真实必要灯的 range 并验证岸面溢光，是待验证方案，不是已完成修复；反射点若在陆地下，还必须调整观察位置。
- **r5 待补：** 保存后的构建标识、11 个原生视角、Terrain audit、岸坡无破片、薄光束、窗/挂灯亮灭倒影、真实路线行走与对应性能。收到真实文件后逐项复核；r5 名称不表示通过。
