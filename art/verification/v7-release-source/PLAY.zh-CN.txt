借光岛 / BORROWED LIGHT
中文试玩说明 · v7 · 2026 年 10 月 21 日

一座小岛，三盏灯，一片等待被看见的星空。
转动灯具，把光送到小路、长椅、书桌与码头；为每个晚归的人留一盏恰好的灯。

开始游玩

1. Windows 离线版：双击本目录中的 Open-Borrowed-Light.cmd。
   启动器会打开 builds\windows\BorrowedLight.exe，默认采用 1440 × 900 窗口。
   请保留整个 builds\windows 文件夹，不能只复制其中的 exe 文件。
2. 在标题画面点击“启程”，或按 Enter，开始新的旅程。
   如有本地进度，可点击“继续上次的旅程”。“启程”会开始新游戏并覆盖旧进度。
3. 运行已经打包的游戏，无需打开 Unity 或 Blender，也无需登录 Unity 账号。
4. 浏览器版：双击 Open-Borrowed-Light-Web.cmd，打开 http://127.0.0.1:8765/。
   启动器会运行本机静态服务器，已用 Microsoft Edge 实测；尚未发布到公网。
   不能直接双击 builds\web\index.html 运行。压缩游戏数据、代码与加载器合计约 48.6 MB，另有载入页图片。
   浏览器与 Windows 版分别保存进度，互不共享；清除本站数据会丢失浏览器存档。
5. 分享 Windows 版可使用 builds\BorrowedLight-Windows.zip，解压后运行 BorrowedLight.exe。

观景与调灯

鼠标左键：选择场景中的灯具，或点击界面按钮。
数字键 1 / 2 / 3：选择对应灯具；尚未解锁的灯不可操作。
A / D 或方向键左 / 右：将选中灯具转到上一个／下一个固定方向。
空格：切换宽光罩与窄光罩。
Enter：目标完成后进入下一章；也可以点击出现的“收下这束星光”按钮。
Tab：在观景调灯与自由漫步之间切换。
Esc：打开或关闭设置；也可以点击右上角“设置”。

灯具界面会显示当前选中的灯、宽窄光罩与照射方向。
左侧文字给出谜题提示，底部显示操作方式；右上角显示照亮位置数量和散光预算。
照明目标全部满足，并且散光不超过 1 时，继续按钮才会出现。
宽光计入 1 点散光；照向没有生活目标的天空／远海时，还会增加散光。
这是便于理解的游戏规则，不是实际照明测量仪表。

自由漫步

W / A / S / D 或四个方向键：沿镜头方向行走。
按住鼠标右键并移动：环顾小岛。
鼠标滚轮：拉近或拉远跟随镜头。
E：靠近灯具时，返回观景调灯并选中附近的灯。
Tab：返回观景调灯；通关后漫步时按 Tab 可重读结尾。

三封守夜人的来信

第一章：“让光，落在需要的地方”
照亮小路与长椅。学会将第一盏灯转向地面，观察宽光能照顾哪些位置。

第二章：“一扇窗，也有它的星空”
为读书的窗户留一束光，同时保持小路和长椅明亮。试着用窄光照顾一个位置。

第三章：“把星光，借给晚归的人”
让小路、长椅、窗户、码头都有光，并将散光控制在预算之内。
需要重新分配已经使用过的灯；四处都亮起来之后，也请看看是否用了太多宽光。

完成第三章后进入星空结尾。
“再借一夜星光”会清除原进度并从第一章开始；“回到岛上”可继续自由漫步。

保存、重开与退出

调整灯具、切换选中灯具以及进入新章节时，游戏会自动保存本地进度。
保存内容是章节、灯具方向、灯罩、开关状态与操作计数。
漫步位置、镜头方向和声音开关不属于本次保存内容。
再次启动时，在标题画面点击“继续上次的旅程”读取进度。
设置中的“重新开始”会清除旧进度，并回到第一章。
右上角“声音”可切换声音；设置内也有声音开关。Windows 版可在设置内退出，浏览器版关闭标签页即可。

当前交付与验证范围

交付平台：Windows 64 位原生离线版本，以及本机浏览器版本。
内容：一座可漫步的小岛、三段递进调灯谜题、星空结尾、环境音乐与灯具音效。
美术制作使用 Blender 4.5 LTS，游戏使用 Unity 6.3 LTS（6000.3.26f1）与 URP。
本轮细化草叶、岩石、人物面部与衣褶，并增大常用操作文字。
Windows v7 构建报告中的运行文件约 150 MiB；分享时请使用完整压缩包。

已验证的本机配置：Intel Core i5-13500H、约 16 GB 内存、Intel Iris Xe 核显，64 位 Windows。
本机运行记录使用 Direct3D 11、1440 × 900 窗口。
v7 原生巡游确认了键盘启动、三章完成、实际行走、设置时停止移动、
关闭设置后恢复移动、通关后返回结尾，以及重新开始。
原生短时采样：菜单约 60、俯视约 60、人物近景约 60、密集草地漫步约 46 FPS，巡游末段约 55 FPS。
木屋、岩石和观星台仪器碰撞，以及步石和观星台接地检查通过；装饰叶片未参与地面碰撞，码头连续甲板接地与两侧护栏阻挡的新增检查通过。
角色保留肘、膝、踝蒙皮关节与地形脚步处理，步速为 1.75 m/s。静止姿态的两只鞋底共 220 个采样点，最小净空约 1.4 毫米；这不代表所有动态姿态、地形与行走路线均已逐点验证。
浏览器 v7 在默认音频策略下通过真实键盘完成三章、刷新续玩、漫步与返回结尾，确认音频上下文恢复，未捕获浏览器异常。
网页每个视角约 3.1 秒、6 次前台区间采样的帧率中位数：菜单约 60、结尾约 54、密集草地漫步约 33 FPS。
以上均为本轮短时样本，不代表恒定帧率或全程最低帧率，也不能据此归因某项优化的性能收益。
网页数值来自 Unity 指标接口；滚动平均值会包含前一视角，因此不将其直接作为当前视角帧率。独立 GPU 诊断与真实键鼠步态记录另存于 art/verification/，采样路线不覆盖所有动态姿态。
Unity 日志仍有隐藏着色器兼容性、WebGL INVALID_ENUM 与音频载入提示；本轮没有出现崩溃或阻断通关的问题，日志并非完全干净。
浏览器记录含缓存，不代表首次网络加载速度；最低配置下限尚未进行不同硬件的分级测试。
因此以上配置是已经验证可运行的基线，不能据此宣称更低配置的性能。
